Audio uses the browser's Web Audio API. Sound begins only after you press Play. Use headphones and start at low volume.

Orchestral sonification

Select Cinematic Orchestra, Classical Symphony, or Scientific Orchestration above. In each mode, cases influence melodic pitch, deaths influence a secondary voice, and changes in cases influence rhythmic accents. These are browser-synthesized instrument-like timbres, not sampled orchestral recordings. All three modes use fixed, documented multivariate mappings.

Bring your own COVID-19 data

Import an Our World in Data COVID CSV with columns location, date, and new_cases / new_deaths or weekly_cases / weekly_deaths. The dashboard aggregates daily observations into calendar weeks; weekly values remain weekly. It does not fetch data automatically.

How to interpret the sound

Pitch

Larger values produce higher tones. Useful for hearing waves and sudden changes.

Rhythm

Larger values produce more rapid pulses within each observation.

Intensity

Larger values produce louder tones, with conservative output levels.

Important caveat

Sound is exploratory, not a diagnostic signal. Reporting delays, revisions, and differences in testing can affect case and death counts.
